## ✨ Features

- **Set Monthly Budget:** Easily define and update your total monthly budget.
- **Track Expenses:** Add new expenses with titles, amounts, and specific categories.
- **Category-wise Filtering:** Filter your expense history by categories (e.g., Food, Transport, Bills, etc.).
- **Real-time Balance Calculation:** Automatically updates total budget, total expenses, and remaining balance.
- **Dynamic Status Indicator:** Visual cues that indicate when you are within budget or overspending.
- **Delete Functionality:** Remove individual expenses to keep records clean and accurate.
- **Modern UI/UX:** Clean, modern fintech dashboard style built with responsive cards, custom badges, and crisp typography.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic layout and input forms.
- **CSS3 / Bootstrap 5:** Custom styling, layout cards, utility classes, and modern UI variables.
- **JavaScript (ES6):** Dynamic DOM manipulation, calculations, filtering, and event handling.
